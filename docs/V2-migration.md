# V2 迁移与验收

## 公开资料映射

| V1 来源 | V2 用途 |
| --- | --- |
| `data.js` 的介绍和教育 | 首页、关于我、教育和证据索引。JCU 为预计 2027 年 2 月毕业。 |
| 三段 `experience` | 职业经历列表与详情。Tyrion.ai 图片标识平台，Basilos 仍为雇主。 |
| 八个 `projects` | 双列作品集、详情与证据索引。保留原日期、贡献、验证结果、链接与截图。 |
| `skills` 及已确认使用场景 | 品牌卡片和工程实践文字标签。证据指向真实项目或经历。未将 AWS 加为已验证技能。 |
| 证书和奖项 | About → Achievements。公开证书使用原 PDF 及原件预览。DrivenData 排名与 Kaggle 训练笔记本分开。 |
| 六类简历 | 简历中心。十二份中英文 PDF、六份中文 Word 和标准英文 Word 保持原件。 |
| 个人项目、推荐信、社交账号 | 保留在原始资料中。V2 公开资产、导航、搜索和 AI 资料均排除家庭项目链接、私人推荐信和 Instagram。 |
| 旧锚点 | 原项目 ID、详情与验证锚点、教育、证书、下载等映射到 V2 路由。 |

构建脚本 `scripts/prepare-v2.mjs` 只复制明示的公共资产并生成 `src/data/public.json`。证据记录有稳定 ID、所属实体、类型、描述、来源、事实、公开状态、语言和已知验证日期。根目录的 V1 源文件与历史提交保持可追溯。由于原仓库为公开仓库，V2 产物的排除措施不会撤回已在 V1 或 Git 历史公开的文件。旧站仍在服务期间应按其当前公开范围理解。

原有证书中 EMAS 与 WSQ 使用之前已处理的公开副本。旧 PDF 和 Word 可能包含原版投递时使用的措辞、联络方式及求职时间，保留原件以满足迁移要求。

## 品牌与人物

- Python 多色标志取自 [Devicon](https://github.com/devicons/devicon/tree/master/icons/python)。ONNX Runtime 图标来自 [ONNX Runtime 品牌文档](https://onnxruntime.ai/docs/reference/citing.html)。其余技术品牌使用 [Simple Icons](https://simpleicons.org/) 的真实品牌图形与品牌色。商标归各权利人。
- `assets/copilot-avatar.webp` 使用内置 imagegen，根据真实西装照制作透明背景的商务人物图。提示词要求同款西装、白衬衫、发型与脸部特征，成熟微笑、柔和海军蓝灯光、无文字或道具。交付是单张 3D 风格渲染，界面通过问候、悬停和处理状态提供轻量反馈。

## 评分与限制

- 模型提取或重新核对去重的要求，并为每项要求返回状态与公开证据 ID。服务端校验 ID、结构和长度，再使用实际出现的维度重新归一化 40/30/20/10 权重。硬性项权重为 3，优先项为 1。匹配记 1，部分匹配记 0.5，未核实和未满足记 0。缺少有效证据的积极判定降为未核实。
- 模型对证据相关性的判断仍可能出错。报告展示证据、明确差距并允许编辑要求后重算。当前设置不会保存访客上传的 JD，发给模型后的处理受模型供应商政策约束。
- 扫描 PDF 缺少可提取文本时，界面提示粘贴文本。预览器默认渲染原 PDF 首页，浏览器渲染失败时显示由原件生成的备用图。
- 前端使用 Hash 路由。深链接可以刷新、返回和分享，静态社交卡片使用站点级元数据。
- 当前工作环境无模型凭证。无配置状态、模拟供应商协议、结构校验、评分和公开产物可本地测试。部署后的真实模型问答与不同 JD 的语义准确性需要在配置后验证。

## 验证命令

`npm run build`、`npm test`、`npm run test:e2e`。外部项目链接在迁移时检查 HTTP 状态，十四条返回 200。HTTP 可访问性不能保证第三方交互服务始终正常或免登录。
